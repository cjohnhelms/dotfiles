How should the editor feel?

Beyond colors — the personality of the experience.

A

Instant & Snappy

No animations, no startup screen. Opens immediately, every action is instant. Pretty visuals, but the engine stays minimal and fast. The philosophy: beauty through restraint.

What you get: Carbonfox + indent guides + git gutter + richer statusline + cursorline + bufferline tabs + auto-pairs + smart comments

B

Alive & Animated

Smooth scrolling, a startup dashboard with recent files, and a gorgeous floating command line (noice.nvim) that replaces the boring bottom bar with styled popups. The editor has presence.

Everything in A, plus: smooth scroll · noice.nvim floating cmdline & notifications · dashboard on startup

C

Subtle Motion

Smooth scrolling only — the one animation that actually helps spatial awareness without feeling like a toy. No dashboard, no floating cmdline. Snappy personality, smooth movement.

Everything in A, plus: smooth scroll only
